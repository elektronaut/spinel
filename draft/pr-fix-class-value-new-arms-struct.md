title: A Class value's positional new builds a Struct, as a static S.new does

Fixes #N.

`k.new(args)` on a Class value, and on a Class read out of a container (`REG.fetch(0).new(...)`), is emitted in `codegen_call.c` as a `switch` on the receiver's `cls_id` with one constructor arm per class and a NoMethodError default. The positional emitter handled a Struct's generated constructor, but for a Struct with its own `initialize` it did `if (initm >= 0) continue;`, with a comment claiming "the test above rules"; nothing above did, so the arm was simply dropped. The boxed-receiver emitter excluded `is_struct` classes outright, so no Struct or Data class had an arm at all. Both calls landed on the NoMethodError default, while the splat form (`emit_class_value_new_kw`) built the same classes. Separately, a plain Struct's generated constructor kept the exact argument-count test, so `k.new(1)` on a two-member Struct, which a static `S.new(1)` nil-fills, also turned into NoMethodError, as did the "struct size differs" ArgumentError for too many arguments.

A Struct with its own `initialize` now constructs through it like any other class: its `sp_<S>_new` already takes that initialize's parameters. The boxed-receiver emitter now gives Struct and Data classes an arm, passing a generated constructor its members typed from the member slots. A plain Struct (not Data, not `keyword_init`) nil-fills missing members and raises ArgumentError `struct size differs` for extra ones in both emitters, matching the static `S.new`. Data and `keyword_init` Structs keep the exact count test, and a Struct whose `initialize` yields still has no arm, since it is spliced at static sites and has no constructor function to call.

Tests: `test/class_value_new_struct_custom_init.rb` is the issue's reproducer (positional `k.new(v)` on a Struct with its own `initialize`, next to the splat form). `test/poly_new_struct_arm.rb` covers the boxed receiver with a plain Struct, a Struct with its own `initialize`, a regular class and a Data class, the nil-fill of a missing member and the "struct size differs" error for extras, both through a boxed receiver and through a Class value. Both fail on master and match CRuby 4.0 with this change. `make gate` is clean apart from the two known sandbox failures, `pkg.tmpdir.tmpdir_expand_usable` and `socket_ipv6_and_class_methods`.
