title: A splat with positionals after it binds from them all beside keyword parameters

Fixes #N.

When a splat is followed by more positional arguments (`f(*a, 3)`), which parameter each trailing argument fills is known only at run time. f09820a5 handled that in `emit_args_filled` by gathering every positional into one array, checking its length against the method's arity and binding from it. That gather was refused whenever the callee had a keyword parameter or the call carried a keyword hash, so `kw(*[1], 2, k: 3)` on `def kw(a, b = 0, k: 1)` fell back to the layout that assumes the splat fills exactly the parameters before the trailing argument: `b` got its default and the 2 was lost, and `kw(*[], 2, k: 3)` bound `a` to nil. It was also refused for any method `opt_before_required` flagged, and that function read `nrequired`, the index past the last required parameter, which a required keyword bumps too, so `def rk(a, b = 0, k:)` looked like it had a leading optional. The instance-dispatch path, `emit_dispatch`, had no gather at all: `O.new.o(*[1], 3)` dropped the 3, and `O.new.m(*[1, 2], 3)` on `def m(a, b)` bound `m(1,2)` and raised nothing.

The gather is now a helper pair shared by both paths. `splat_gather_applies` decides whether a call qualifies: one splat with positionals after it, into a method with no `*rest`, no `**kwrest`, no leading optional and no synthesized parameter. Keyword parameters are allowed, and so is a keyword hash as long as it binds as keywords rather than as one more positional. `emit_splat_gather` builds the rooted array and emits the `ArgumentError` check. On the dispatch path a gathered element is boxed, so it is unboxed into a typed parameter. The optional guard that falls back to a default past the end of the array now also checks the parameter's `pdefault`, since an optional ahead of a required keyword sits below `nrequired`. `opt_before_required` now reads the def's Prism parameters, where an optional is funded late exactly when the list has both optionals and posts, and falls back to `nrequired` only for a scope with no def parameter list (a synthesized one, a block's). Its signature becomes `opt_before_required(Compiler *c, Scope *m)`, and every caller moves to it, including the ones in `poly_arm_count` and the poly receiver arm in `src/codegen_call.c` and the new `emit_call_arity_check` (#4970). Calls without a trailing positional after the splat, and methods with a rest or kwrest, keep their existing layouts.

Tests: `test/splat_trailing_positional_keywords.rb` covers `kw` and `rk` with a trailing positional and keywords (literal and `**h`), a count that is too high, and no keywords at all; the same shapes on an instance, including `o.m(*:y, 2)` with a scalar splat and `o.m(*[1, 2], 3)` raising `ArgumentError`; a typed `def ti(a, b = 5)` where the gathered element is unboxed, directly and on an instance; and a poly receiver calling `q.m(*[1], 2)` and `q.m(*[], 2)`. It fails on master and matches CRuby 4.0 with this change. `make gate` is clean apart from the two known sandbox failures, `pkg.tmpdir.tmpdir_expand_usable` and `socket_ipv6_and_class_methods`.
